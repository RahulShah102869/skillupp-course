# 🎓 SkillUp Course – Online Learning Platform

A modern and responsive online course platform designed to help students upgrade their skills through premium courses in programming, development, and communication.

🌐 **Live Demo:** [Visit SkillUp Course](https://skillupp-course.netlify.app/)

---

## 🚀 About The Project

SkillUp Course is an online learning website where users can explore different courses, add their favourite courses to a shopping cart, and proceed to checkout.

The platform focuses on providing a simple, user-friendly, and responsive experience for learners.

## ✨ Features

- 📚 **12+ Premium Courses** – Explore courses in different skill categories.
- 🛒 **Shopping Cart** – Add and manage selected courses.
- 💰 **Discount System** – Get a 10% discount on the cart subtotal.
- 🧾 **Checkout System** – Proceed through the order placement flow.
- 📱 **Responsive Design** – Works across desktop, tablet, and mobile devices.
- 🎨 **Modern UI** – Clean and user-friendly interface.
- 🧭 **Easy Navigation** – Home, Courses, About, and Contact sections.
